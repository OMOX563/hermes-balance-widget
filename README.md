# hermes-balance-widget

Hermes 桌面客户端的多厂商余额挂件：右下角常驻一个卡通角色，点击弹出漫画式玻璃气泡展示余额 / 额度 / 用量，覆盖九家厂商——DeepSeek · MiniMax · 智谱 GLM · Kimi · MiMo · ChatGPT · Claude · Gemini · Grok，每家配专属形象，**随你当前使用的模型自动换角色**（按模型名关键词匹配，不分大小写）。

> 取数模板结构与字段语义移植自 [DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)（MIT © MeteorNOX），按九家清单重写为 Hermes 磁盘插件。

## 九家取数层级

| 层级 | 厂商 | 展示 |
|---|---|---|
| 真余额 | DeepSeek、Kimi / Moonshot（CN） | 余额数字（¥/$）、总额、今日已用 |
| 订阅额度 | MiniMax Coding、智谱 GLM Coding | 5h / 周窗口剩余 % |
| 探活（官方无余额接口） | MiMo、ChatGPT、Claude、Gemini、Grok | key 有效性 + 余额「—」 |

> 官方不提供「用 key 查余额」接口的厂商不是缺陷是现实——挂件如实显示探活状态，不伪造数字。

## 功能

- **模型自动换角色**：订阅 `host.state.model`，模型名关键词命中即换形象与取数目标（`XIAOMI/MIMO-V2.6-PRO` → MiMo，大小写不分）；未命中回退到设置页选的主厂商，可一键关闭
- **漫画气泡弹窗**：点角色弹出液态玻璃信息卡，紧贴角色头顶、三角尖角指向角色；日间自动白玻璃、夜间自动深玻璃（跟随 `--theme-background-seed`）
- **Q 弹按压**：按下压缩、松开弹性回弹，配按压音效
- **拖拽 + 贴边吸附**：按住角色拖动，靠近屏幕边缘自动吸附，位置持久化
- **大小调节**：60%–160% 滑杆实时缩放，就地缩放不位移；基准尺寸 235px（336px 的 70%）
- **余额预警**：低于阈值时 toast 提示 + 预警音（每家每次穿越只警一次）
- **今日已用**：本地观测余额下降累计（充值不冲掉，跨天自动重置）
- **每轮消耗**：订阅会话状态，按 `cost_usd` 增量结算展示
- **任务结束音**：一轮回答完成时播放提示音
- **分角色随机语句**：每家一张 ≥5 条的搞怪语句池（取材中文社区对各家模型的调侃），气泡底部轮换；换角色即换池
- **60s 轮询 + 手动刷新**：卡内「刷新」按钮随时取最新

## 安装（Hermes 桌面端）

1. 从 [Releases](../../releases) 下载最新版的 `plugin.js`
2. 打开 Hermes 的 **技能与工具 → 插件** 页，点 **「打开插件目录」**（文件夹图标）——这会直接打开本机真实的插件根目录，不要手动猜路径
3. 在插件根目录下新建文件夹 `hermes-balance-widget`，把 `plugin.js` 放进去
4. 回到插件页点 **刷新** ↻

**成功信号**：出现 toast「💰 余额挂件插件已加载」，且插件列表里出现「余额挂件」条目；同时右下角出现挂件角色。

> 改动单个文件不会触发 watcher 重载（它只监听目录级事件），每次都要手动点刷新。

## 配置教程

### 1. 填 API key（必做）

打开设置页，三选一：

- **侧栏**：左下导航点「余额挂件」
- **命令面板**：`Ctrl+Shift+K` → 「余额挂件：打开设置」
- 直接访问路由 `/balance-widget`

设置页里每家一行卡片：

| 字段 | 说明 |
|---|---|
| 层级徽标 | 真余额 / 订阅额度 / 探活——决定挂件显示什么数据 |
| `DEEPSEEK_API_KEY` 等 | 该厂商的 API key，密码框输入，**只存本机插件存储（localStorage），不出本机** |
| 测试连通性 | 不填 key 直接点会提示；填了真 key 会向厂商官方接口发一次真实查询，显示余额 / 窗口 / 探活结果 |

各厂商 key 获取处：

| 厂商 | 控制台 |
|---|---|
| DeepSeek | platform.deepseek.com → API Keys |
| MiniMax | platform.minimaxi.com → 接口密钥（Coding 计划另有专属接口） |
| 智谱 GLM | open.bigmodel.cn → API Keys |
| Kimi / Moonshot | platform.moonshot.cn → API Keys |
| MiMo | token-plan 端点（当前无余额接口，填 key 仅探活） |
| ChatGPT / Claude / Gemini / Grok | 各家官方 API 控制台（均无余额接口，填 key 仅探活） |

### 2. 挂件控制（设置页顶部）

| 设置 | 说明 |
|---|---|
| 显示右下角挂件 | 总开关 |
| 挂件大小 | 60%–160% 滑杆，**拖动实时生效**，就地缩放不改变挂件位置 |
| 跟随当前模型自动换角色 | 开启时按当前模型名关键词（不分大小写）自动换形象与取数；关闭则固定为主厂商 |
| 主厂商 | 九宫格点按即切换——自动换角色开启时它是「关键词未命中」的回退角色 |
| 音效（按压 / 任务结束 / 预警） | 总开关 |
| 音量 | 0–100%，关总开关时禁用 |
| 弹窗随机语句 | 气泡底部那行小字 |
| 余额预警 + 预警阈值 | 低于阈值（如 `5`）时 toast + 提示音，仅真余额厂商生效；回升到阈值以上自动复位 |

所有设置即时落盘，重新加载插件后保持。

### 3. 日常交互

- **点角色**：Q 弹按压 → 弹出玻璃气泡（再点一次或点外部关闭）
- **按住角色拖动**：移动位置，靠近屏幕边缘自动吸附
- **气泡内「刷新」**：立即重新取数
- **切主题**：日间自动白玻璃、夜间自动深玻璃，无需手动设置

## 数据说明

- 「今日已用」「每轮消耗」均为本地观测估算：前者靠余额下降累计，后者靠会话 `cost_usd` 增量——充值不会冲掉当日已用，跨天自动清零
- 探活类厂商余额恒为「—」，这不是 bug

## 开发

```bash
python build.py        # 组装单文件 plugin.js（逐条 assert 手术 + node --check 语法门）
node test/smoke.mjs    # 冒烟：九家模板 / 取数三态（mock fetch）/ 模型关键词匹配 / 分池语句 / 注册结构 / 挂件静态断言
```

素材管线（`tools/`）：`compress_assets.py` 压缩原图 → `cutout_rembg.py` 语义分割抠图（rembg + alpha matting）→ `diag_edge.py` 边缘质量验收。

改动后到 **技能与工具 → 插件 → 刷新** 重载（watcher 不覆盖已知目录的单文件修改）。

## 隐私

- 各厂商 API key 由用户在设置页填写，**仅存本机插件存储，不出本机**
- 网络请求只有向各厂商官方接口发起的余额查询，无任何第三方上报
- `.gitignore` 拦截 `*.secret` / `.env`
- 本仓库不含任何本机路径、用户名、密钥或环境标识
