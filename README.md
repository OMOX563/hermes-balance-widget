# hermes-balance-widget

Hermes 桌面客户端的多厂商余额挂件：右下角常驻一个卡通角色，点击弹出漫画式玻璃气泡展示余额 / 额度 / 用量，覆盖九家厂商——DeepSeek · MiniMax · 智谱 GLM · Kimi · MiMo · ChatGPT · Claude · Gemini · Grok，每家配专属形象，**随你当前使用的模型自动换角色**（按模型名关键词匹配，不分大小写）。

> 取数模板结构与字段语义移植自 [DeepSeek-Balance-Whale-Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget)（MIT © MeteorNOX），按九家清单重写为 Hermes 磁盘插件。

## 九家取数层级（13 个取数源，订阅与按量付费分条）

| 层级 | 源 | 厂商 | 展示 |
|---|---|---|---|
| 按量付费 · 真余额 | 3 | DeepSeek、Kimi（CN）、Kimi（国际） | 余额数字（¥/$）、总额、今日已用 |
| 订阅额度 | 5 | MiniMax（CN/国际）、智谱 GLM（CN/国际）、Kimi Coding | 5h / 周窗口剩余 % |
| 探活（官方无余额接口） | 5 | MiMo、ChatGPT、Claude、Gemini、Grok | key 有效性 + 余额「—」 |

同一厂商的**订阅与按量付费分开成条**：如 Kimi = 按量（CN）+ Kimi Coding 订阅 + 按量（国际）三源，MiniMax / 智谱 = 国内 + 国际两源，各源独立填 key、独立展示。

> 官方不提供「用 key 查余额」接口的厂商不是缺陷是现实——挂件如实显示探活状态，不伪造数字。按量消费类 Admin 接口（OpenAI / Anthropic 管理密钥、MiniMax admin key）与各家按量余额缺口均在设置页注明。

## 功能

- **模型自动换角色**：订阅 `host.state.model`，模型名关键词命中即换形象与取数目标（`XIAOMI/MIMO-V2.6-PRO` → MiMo，大小写不分）；未命中回退到设置页选的主厂商，可一键关闭
- **漫画气泡弹窗**：点角色弹出液态玻璃信息卡，紧贴角色头顶、三角尖角指向角色；日间自动白玻璃、夜间自动深玻璃（跟随 `--theme-background-seed`）
- **Q 弹按压**：按下压缩、松开弹性回弹，配按压音效
- **拖拽 + 贴边吸附**：按住角色拖动，靠近屏幕边缘自动吸附，位置持久化
- **盒贴角色（素材紧裁）**：九张形象从 384×214 画布裁到各自 alpha bbox（宽 160–288 随角色走、高统一 203），左右/上方画布留白清零——盒即角色，点击不会落到透明空气上，侧翼自然穿透回页面，气泡尖角贴发顶
- **今日估算（token 计价）**：官方无余额接口的厂商（探活层）按本机会话的输入/输出 token × 每百万单价估算今日消费，缓存命中部分按命中单价计；每家可自定义四项单价（输入/输出/缓存命中/缓存创建，留空回落默认牌价）
- **每轮消耗兜底**：宿主未报 `cost_usd` 时按本轮 token 增量 × 自定义单价估算，币种跟随单价表
- **分时自动切价（DeepSeek / GLM / MiMo）**：配置价 = 日间/高峰价，命中非高峰窗口自动乘系数，档位名自定义——DeepSeek **小楠梁时段**（工作日 9-12/14-18）原价、**梁圣时段** ×0.5（周末全天）；GLM **贼时段**（工作日 14-18）原价、**一哥时段** ×0.5（Coding Plan 积分 50% 抵扣）；MiMo **bug时段** 原价、**雷峰塔时段**（0:00-8:00）×0.8。窗口按北京时间判定（+8h 换算，与本机时区无关）；今日 token 按记账当刻所在窗口分流双桶，跨窗口用量各按各价结算，弹窗「当前时段」行实时显示档位
- **开窗换梗**：每次点击角色弹出弹窗都重掷一条随机语句（保证与上一条不同），弹窗开启期间仍每 8s 轮换
- **大小调节**：60%–160% 滑杆实时缩放，就地缩放不位移；基准 = 角色高 124px、宽随各家形象实际宽窄（素材已紧裁到 alpha bbox，盒贴角色无留白）
- **余额预警**：低于阈值时 toast 提示 + 预警音（每家每次穿越只警一次）
- **今日已用**：本地观测余额下降累计（充值不冲掉，跨天自动重置）
- **每轮消耗**：订阅会话状态，按 `cost_usd` 增量结算展示
- **任务结束音**：一轮回答完成时播放提示音
- **分角色随机语句**：每家一张 ≥5 条的搞怪语句池（取材中文社区对各家模型的调侃），气泡底部轮换；换角色即换池
- **60s 轮询 + 手动刷新**：卡内「刷新」按钮随时取最新

## 安装（Hermes 桌面端）

1. 从 [Releases](../../releases) 下载最新版的 `plugin.js`
2. 打开 Hermes 的 **技能与工具 → 插件** 页，点 **「打开插件目录」**（文件夹图标）——这会直接打开本机真实的插件根目录，不要手动猜路径
3. 在插件根目录下新建文件夹 `hermes-balance-widget`，把 `plugin.js` 放进去
4. 回到插件页点 **刷新** ↻

**成功信号**：出现 toast「💰 余额挂件插件已加载」，且插件列表里出现「余额挂件」条目；同时右下角出现挂件角色。

> 改动单个文件不会触发 watcher 重载（它只监听目录级事件），每次都要手动点刷新。

## 配置教程

### 1. 填 API key（必做）

打开设置页，三选一：

- **侧栏**：左下导航点「余额挂件」
- **命令面板**：`Ctrl+Shift+K` → 「余额挂件：打开设置」
- 直接访问路由 `/balance-widget`

设置页里每家一张卡，卡内**每个取数源一行**（订阅与按量付费分列）：

| 字段 | 说明 |
|---|---|
| 源标题 + 层级徽标 | 「订阅 · 国内」「按量付费 · 国际」等——决定该行数据形态 |
| `DEEPSEEK_API_KEY`、`KIMI_CODING_KEY` 等 | 该源的 key，密码框输入，**只存本机插件存储（localStorage），不出本机**；首源沿用旧存储键，升级零迁移 |
| 测试连通性 | 不填 key 直接点会提示；填了真 key 会向厂商官方接口发一次真实查询，显示余额 / 窗口 / 探活结果 |

各厂商 key 获取处：

| 源 | 控制台 |
|---|---|
| DeepSeek 按量付费 | platform.deepseek.com → API Keys |
| MiniMax 订阅（国内） | platform.minimaxi.com → 接口密钥（仅 Coding Plan 订阅账号有效） |
| MiniMax 订阅（国际） | api.minimax.io 对应平台，独立账号与 key |
| 智谱 GLM 订阅（国内） | open.bigmodel.cn → API Keys（订阅与按量充值账号同口，按 type 识别） |
| 智谱 GLM 订阅（国际） | z.ai 平台，独立账号与 key |
| Kimi 按量（国内） | platform.moonshot.cn → API Keys |
| Kimi Coding 订阅 | kimi.com/code 控制台 → 独立 key（与 Moonshot API key 不通用） |
| Kimi 按量（国际） | api.moonshot.ai 对应平台，独立账号与 key |
| MiMo | token-plan 端点（无余额接口，填 key 仅探活） |
| ChatGPT / Claude / Gemini / Grok | 各家官方 API 控制台（均无余额接口，填 key 仅探活） |

未配置的源在弹窗里显示「未配置 key」，不影响同厂商其他源展示。

### 2. 挂件控制（设置页顶部）

| 设置 | 说明 |
|---|---|
| 显示右下角挂件 | 总开关 |
| 挂件大小 | 60%–160% 滑杆，**拖动实时生效**，就地缩放不改变挂件位置 |
| 跟随当前模型自动换角色 | 开启时按当前模型名关键词（不分大小写）自动换形象与取数；关闭则固定为主厂商 |
| 主厂商 | 九宫格点按即切换——自动换角色开启时它是「关键词未命中」的回退角色 |
| 音效（按压 / 任务结束 / 预警） | 总开关 |
| 音量 | 0–100%，关总开关时禁用 |
| 弹窗随机语句 | 气泡底部那行小字 |
| 余额预警 + 预警阈值 | 低于阈值（如 `5`）时 toast + 提示音，仅真余额厂商生效；回升到阈值以上自动复位 |

**单价（每百万 tokens）**：每家厂商卡底部有四格单价输入——输入 / 输出 / 缓存命中 / 缓存创建（厂商币种，缓存创建暂无宿主数据源、估算不计）。留空 = 用内置默认牌价（来自 2026-10 社区/官方文档搜索，标注在栏位旁，牌价会随厂商调价过期）；填 `0` = 该项免费。探活层厂商的弹窗主数值即「今日估算」，设置页单价栏下方同步显示今日估算与 token 用量。

所有设置即时落盘，重新加载插件后保持。

### 3. 日常交互

- **点角色**：Q 弹按压 → 弹出玻璃气泡（再点一次或点外部关闭）
- **按住角色拖动**：移动位置，靠近屏幕边缘自动吸附
- **气泡内「刷新」**：立即重新取数
- **切主题**：日间自动白玻璃、夜间自动深玻璃，无需手动设置

## 数据说明

- 「今日已用」「每轮消耗」均为本地观测估算：前者靠余额下降累计，后者靠会话 `cost_usd` 增量——充值不会冲掉当日已用，跨天自动清零
- 探活类厂商余额恒为「—」，这不是 bug

## 开发

```bash
python build.py        # 组装单文件 plugin.js（逐条 assert 手术 + node --check 语法门）
node test/smoke.mjs    # 冒烟：九家模板（13 源）/ 取数三态 / 模型匹配 / 分池语句 / token 计价与观测 / 注册结构
```

素材管线（`tools/`）：`compress_assets.py` 压缩原图 → `cutout_rembg.py` 语义分割抠图（rembg + alpha matting）→ `diag_edge.py` 边缘质量验收。

改动后到 **技能与工具 → 插件 → 刷新** 重载（watcher 不覆盖已知目录的单文件修改）。

## 隐私

- 各厂商 API key 由用户在设置页填写，**仅存本机插件存储，不出本机**
- 网络请求只有向各厂商官方接口发起的余额查询，无任何第三方上报
- `.gitignore` 拦截 `*.secret` / `.env`
- 本仓库不含任何本机路径、用户名、密钥或环境标识
